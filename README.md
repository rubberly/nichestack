# Nichestack

One Next.js codebase powering four niche subscription products:

- **PhotoVault**: private file sharing for photographers and contractors
- **Client Portal**: branded portals for viewing files, quotes and invoices
- **Storage Facility**: unit listings, online bookings and rent collection
- **QuoteFollow**: automatic follow-ups on quotes
